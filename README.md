# ⚡ CloudVerse: Next-Gen Cloud Orchestration

CloudVerse is a high-performance, Vercel-inspired cloud management platform designed for modern engineering teams. It provides an immersive Cyberpunk UI, real-time deployment monitoring, global edge network visualization, and robust infrastructure orchestration.

![Landing Page Preview](./brain/936c9124-ac12-48bb-a870-cc7f49999777/landing_page_mobile_1774636539881.png)

## 🚀 Features

- **GitHub & Manual Imports**: Deploy repositories directly or upload local project folders.
- **Real-time Deployments**: Monitor build sequences and logs in real-time.
- **Premium Cyberpunk UI**: Built with advanced glassmorphism, dynamic mesh gradients, and `react-hot-toast` notifications.
- **Cloud-Native Database**: Fully backed by Supabase (PostgreSQL) for persistence across edge environments.
- **Single-Container Architecture**: Optimized production images running both the frontend (Vite/Nginx) and backend (Node.js) in a unified Docker container.

## 🛠️ Tech Stack

- **Frontend**: React 19, Tailwind CSS, Lucide Icons, Vite.
- **Backend**: Node.js, Express, Supabase JS Client, Winston (Logging).
- **Database**: Supabase PostgreSQL.
- **Infrastructure**: Docker, Nginx (Reverse Proxy).
- **Deployment**: Render.com (1-click Web Service).
